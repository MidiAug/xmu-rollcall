# 接口流程参考

这里保存从授权操作的 HTTP 导出中提炼的协议资料，可单独分享本目录。它是指定时间的观察记录，不是厂商正式 API 契约；不会改变客户端的权限和提交确认规则。

| 入口 | 内容 |
| --- | --- |
| [畅课 / TronClass](tronclass/README.md) | 助教作业、整批最终成绩、评分、导出和打包 |
| [信息门户认证流程](portal-login.md) | 门户页面、IDS、CAS 回跳与门户会话的边界 |

原始个人数据不进入本目录。路径中的业务 ID 改为占位符；请求头只保留名称；参数和响应值只保留类型、数组规模，以及明确列出的少量根级状态标记。姓名、学号、真实成绩、票据、账号、密码、文件名、下载地址和用户正文均不保留。动态 JSON 键也需脱敏。

每批资料保留原文件 SHA-256、字节数、修改时间、HTTP Date 范围和逐请求导出序号。原文件修改时间是导出线索；HTTP Date 是响应头中的服务器时间，均不冒充客户端当前复测时间。以后接口有变化时新增带日期的批次并链接差异，不覆盖旧观察。

本目录不包含原始抓包备份。未保留静态资源、二进制附件和第三方后台流量，因此不能用于保真重放。分享整个仓库之前仍须分别检查其他目录和 Git 历史。
