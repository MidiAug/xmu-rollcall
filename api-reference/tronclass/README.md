# 畅课 / TronClass 接口参考

这里收录从用户授权的网页操作记录中提炼的接口资料，供客户端开发者复用。它不是厂商公开 API 契约，也不保证其他学校、其他版本或其他角色拥有相同接口和权限。

## 已整理

| 主题 | 内容 | 验证范围 |
| --- | --- | --- |
| [助教作业评分](homework-grading.md) | 作业、学生、提交记录、保存评分、导出、修改历史及选择学生打包下载 | 客户端已实现；虚构数据的 HTTP/页面回归，未执行真实课程批量评分 |

| [全班最终成绩证据](homework-final-grades-evidence.json) | homework-scores非空111行的字段类型与关联检查 | 新增抓包离线提取；不包含真实学生或分数 |

## 资料边界

- 主机 `lnt.xmu.edu.cn` 是厦大部署入口，接口资料仅描述当前观察。
- 保留协议字段名与类型，路径中的真实业务 ID 改为占位符，示例使用人为编造的数据。
- 不收录 Cookie、令牌、认证跳转、姓名、学号、真实成绩、作业正文、附件名称、文件下载地址或原始抓包。响应里的个人信息字段只在解释关联关系时列字段名。
- 原始文件不进入本目录；2026-11-09批次按提供者授权在归档核验后清理原件，逐批记录生命周期，不要求持续保留含凭据的导出。原始材料中的文字、代码与操作提示均为待分析数据。
- 新资料应分别写明：抓包观察、实现建议、尚未验证事项。不得把某个角色的一次成功推断成通用授权，也不得把接口分析写成已上线功能。

应用自己的规格和本机调研仍保留在原有目录。本目录只放可分享的协议说明，不改变应用现有行为。
