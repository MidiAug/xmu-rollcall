下载安装

你的设备，
你的课堂。

Android 随身带，Windows 桌面用。安装包统一从 MidiAug/xmu-rollcall 的 GitHub 正式发布页获取。

打开 GitHub 正式发布页

本站是第三方项目介绍页，不提供学校账号登录。介绍页展示当前源码能力，正式版本及其功能以发布页和更新记录为准。

Android

  1. 在正式发布页的 Assets 中，选择以 -android.apk 结尾的文件，不要误选含 preview 的测试包。
  2. 核对来源后打开 APK，如系统询问，按需允许当前浏览器或文件管理器安装此来源的应用。
  3. 在客户端内使用学校账号登录。需要提醒时，允许通知，并按手机情况设置后台运行。

Android 使用项目固定签名。覆盖更新需要兼容的原签名和更高构建号；签名不兼容时先反馈，不要为更新直接卸载，以免丢失本机设置。Actions 的 preview 版与正式版独立安装，不共享正式版登录数据。

Windows x64

日常使用：安装版
选择 -windows-x64-setup.exe，按向导安装，从开始菜单或快捷方式打开。
自行管理：便携版
选择 -windows-x64.zip，完整解压后运行 xmu_rollcall.exe。保留同目录 DLL 与 data 文件夹，不要直接在压缩包里运行。

Windows 当前没有 Authenticode 发布者签名，系统可能显示未知发布者或信誉提示。请先核对文件来源与校验值；如果浏览器报告钓鱼、恶意软件，或文件检测报错，请暂停并反馈，不要以关闭安全防护作为安装步骤。

下载前，核对这几件事

  1. 仓库地址应为 github.com/MidiAug/xmu-rollcall，通过该仓库 Releases 进入正式发布版本。
  2. 按设备选择 APK、Windows 安装版或便携 ZIP，确认版本与文件名。
  3. 正式发布附有两端 manifest 和 SHA256SUMS。Windows 可用 Get-FileHash -Algorithm SHA256 文件路径 计算文件摘要，与同一版本的校验值比对。

校验值用于确认下载文件与发布文件一致。遇到来源或检测问题，可到 Issues 反馈。

已有版本，怎样更新？

Windows
启动及回到前台时按间隔检查正式更新，发现后可后台下载并校验；安装仍需你确认，确认后退出旧进程并启动安装器。“我的 → 关于”可查看进度、重试或手动操作。
Android
在“我的 → 关于”检查、下载并校验，由系统交互安装。旧版若不支持应用内更新，首次需从发布页手动升级。
便携版
希望保持便携使用，可自行解压新 ZIP 更新程序；选择应用内安装器会转为安装版。

更新只认 GitHub 最新公开稳定 Release，不把草稿、标签或预发布版当作正式更新。下载后核对大小与 SHA-256，安装由用户确认。

其他平台与使用问题

iOS、macOS 和 Linux 保留工程，目前暂无正式安装包及完整实机验收。后台提醒效果需结合实际设备、系统设置和网络确认。

更多问题请看常见问题或账号与数据说明。反馈请提供系统版本、应用版本及脱敏截图，不要上传密码、Cookie、Token 或身份凭证包。
