GET STARTED / 安装指南

把课堂装进口袋，
或者放在桌面。

厦大签到（xmu-rollcall）目前主要支持 Android 和 Windows。安装包统一从项目的 GitHub Release 获取。

打开最新正式发布页 ↗

Android 安装

  1. 打开最新正式发布页，展开 Assets，下载以 -android.apk 结尾的安装包。
  2. 打开 APK；如系统询问，按需允许当前浏览器或文件管理器安装此来源的应用。
  3. 安装后打开厦大签到，使用学校账号登录畅课。需要后台提醒时，允许通知，并按手机设置允许后台运行。

Android 当前沿用项目开发签名。覆盖更新要求安装包使用兼容签名和更高构建号；preview 测试版与正式版独立安装。遇到签名不兼容时，先核对安装包来源和版本，避免直接卸载丢失本机设置。

Windows 安装

适用于 Windows x64，按使用方式选择一个包：

安装版：-windows-x64-setup.exe
运行安装向导，选择安装目录，再从开始菜单或快捷方式打开应用。
便携版：-windows-x64.zip
完整解压后运行 xmu_rollcall.exe，保留同目录 DLL 和 data 文件夹；不要直接在压缩包中运行。

Windows 安装程序尚无发布者数字签名，系统可能显示未知发布者。请核对来自本项目 Release，按发布页提供的校验信息确认文件；如无法确认，暂停安装并反馈。

后续怎样更新？

进入“我的 → 关于”查看更新，也可回到 Release 手动下载。应用不会自动下载或静默安装；下载完成会校验大小与 SHA-256，再由你确认安装。Windows 确认安装后会停止检测并退出。

便携版使用应用内安装器更新会转为安装版；希望继续便携使用时，从 Release 下载新的便携 ZIP。

下载或登录遇到问题？

先查看常见问题。需要反馈时，请在 GitHub Issues 提供系统版本、应用版本、复现步骤及脱敏截图，不要上传账号密码、Cookie 或 Token。
