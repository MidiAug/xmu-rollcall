常见问题

先了解，
再开始。

关于项目身份、功能范围与日常使用。具体可安装版本，以 GitHub 正式发布页为准。

这是学校官方应用吗？

不是。厦大签到（xmu-rollcall）是 MidiAug 独立维护、采用 MIT 许可证的第三方开源客户端，与厦门大学及 TronClass 官方无隶属关系。网站只用于介绍和安装指引，不提供学校账号登录。

支持哪些设备和学校？

当前面向厦门大学畅课（TronClass），提供 Android 与 Windows x64 安装包。不采用旧教务签到协议，也不承诺兼容其他学校。iOS、macOS 和 Linux 保留工程，但暂无正式安装包及完整实机验收。

会自动替我签到吗？

自动签到默认关闭。主动开启后，数字签到按设置的人数或比例等待；雷达还需要当前账号、当前课程已配置的位置。没有位置时只提醒，提交失败或结果不确定时需手动处理。提交结果可在页面查看。请确认签到内容与位置真实有效，并遵守学校规定。

可以查看、提交作业吗？

学生端可查看作业说明、附件、截止时间、提交情况和成绩，按课程整理待办。学生作业提交仍回畅课完成。助教端有独立的批改能力，不能把助教权限理解为学生端提交功能。

助教作业支持什么？

电脑端可查看整班名单与成绩、行内评分、查看评分记录、CSV 预览批量评分，以及全部或选人打包下载。手机端只读查看。适用于普通个人百分制作业，使用学校账号已有的助教权限。

校园工具包括哪些？

本周与学期课表、课程详情和上课地点、三校区地图与建筑档案、成绩与 GPA、本科考试安排和学年校历。成绩区分本科与研究生规则，可按总绩点、学年、近学期或学期选范围并勾选课程计算。数据可读范围由当前账号权限决定。

已浏览的地图区域会缓存在本机，查看新区域需要联网。课表、成绩等页面会先显示已有数据，再按需更新。

账号密码和协助身份怎样保存？

客户端连接学校认证与畅课服务完成登录和业务访问，凭据使用设备上的系统安全存储。主账号与协助身份分别保存会话、缓存和检测配置，切换查看身份不会自动停止其他账号的任务。

协助身份涉及凭证包，只应在双方知情同意的可信设备之间使用。不要公开或上传凭证包。退出主号后，缓存与已导入的协助身份可在应用内分别管理。详见账号与数据说明。

为什么没有收到后台提醒？

Android 需允许通知，并检查后台运行与省电设置；Windows 需保持应用运行，睡眠或退出后不继续检测。先在提醒设置发送测试通知并确认收到。锁屏、厂商省电及网络行为需要结合设备验证，不承诺所有设备后台常驻。

浏览器或系统提示危险，怎么办？

先暂停访问或安装，记录完整 URL、提示类型、时间与浏览器版本，向维护者反馈。网站钓鱼拦截、下载文件检测和未知发布者提示需要分别调查。维护者会根据具体提示检查并向对应安全平台申请复核。

在哪里看源码、更新与反馈？

前往 GitHub 源码仓库、正式发布页或 Issues。反馈提供系统与应用版本、操作步骤和脱敏截图，不要附密码、Cookie、Token 或他人的个人数据。

首页使用当前页面与演示数据。手机作业图来自 Android 15 模拟器的原生运行截图，桌面图为页面组件渲染。
