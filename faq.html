QUESTIONS / 常见问题

使用之前，
你可能想知道。

关于厦大签到（xmu-rollcall）的支持范围、账号与日常使用。

厦大签到是学校官方应用吗？

不是。厦大签到是由 MidiAug 维护、采用 MIT 许可证的第三方开源项目，面向厦门大学畅课（TronClass）。本项目不代表厦门大学或 TronClass 官方。

厦大畅课有 Windows 客户端可以用吗？

本项目提供 Windows x64 客户端，也提供 Android 版本，支持课堂签到、作业查看、课表管理和多身份切换。请从安装指南进入项目正式发布页。仓库保留 iOS、macOS 和 Linux 工程，但尚未完成这些平台的完整实机验收。

其他学校或旧教务系统能用吗？

当前仅面向厦门大学畅课，连接学校认证与畅课服务。不支持旧教务签到协议，也不承诺兼容其他学校的 TronClass 部署。

账号密码保存在哪里？

账号凭据使用设备上的系统安全存储，登录和课程请求会连接学校服务。主号与各协助身份使用独立会话。退出登录会清除主号凭据，课程等缓存默认保留；共用设备时请同时留意本机缓存与已导入身份。

协助功能涉及主动导入或导出身份凭证包，只应在双方知情同意的可信设备之间使用。不要公开凭证包，也不要把它上传到 Issues、聊天群或网页。

会自动替我签到吗？

自动签到默认关闭，检测负责发现签到。主动开启自动签到后，数字签到遵循设置的等待人数或比例；雷达签到还需要当前账号、本课程的有效位置。没有位置、提交失败或结果不确定时，请打开签到页手动处理。二维码识别不等于提交成功，应以页面结果为准。

能在这里提交作业吗？

目前作业功能只读，可查看待办、截止时间、提交和批改状态，并按课查看作业。提交作业请回畅课完成。

为什么没有收到后台提醒？

Android 请先允许通知并检查后台运行与省电设置；Windows 请保持应用运行，睡眠或退出后不会继续检测。可到应用提醒设置发送测试通知，并确认实际收到。厂商省电、锁屏与校园网络效果需要结合设备验证。

在哪里反馈故障、查看源码和更新？

源码在 MidiAug/xmu-rollcall，更新在 GitHub Release，问题请提交到 Issues。附系统和应用版本、操作步骤与脱敏截图；不要附密码、Cookie、Token 或凭证包。
