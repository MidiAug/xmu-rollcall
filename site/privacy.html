账号与数据说明

知道数据去哪，
再决定使用。

厦大签到是 MidiAug 独立维护的第三方开源项目，与厦门大学及 TronClass 官方无隶属关系。以下区分介绍网站与已安装客户端。

这个网站做什么？

本站提供功能介绍、界面预览和安装指引，不提供校园账号登录、密码输入、凭证上传或在线签到。本站没有配置统计脚本、广告、外部字体服务或业务追踪 Cookie，正文无需 JavaScript 即可阅读。

网站由 GitHub Pages 托管。访问会向托管服务发送正常的网络请求，相关基础设施数据处理适用 GitHub 隐私声明。打开 GitHub 发布页、源码或 Issues 后，进入的是 GitHub 服务。

客户端怎样登录？

客户端使用学校统一身份认证账号，连接学校认证与畅课服务完成登录和业务访问。可在源代码中核对实现；本项目不代表学校提供认证服务。请仅在确认来源的客户端内操作，不在介绍网站或反馈区输入校园密码。

账号凭据和令牌使用设备上的系统安全存储，课程、作业、成绩等业务缓存保存在本机。业务缓存与凭据分别管理，请妥善保管设备。

多身份、缓存与退出登录

主账号与各协助身份使用独立会话、缓存和检测配置。协助功能可能主动导入、导出身份凭证包，只应在双方知情同意的可信设备之间使用，不要公开分享或上传到 Issues、聊天群或网页。

退出登录会清除主号凭据，课程等缓存默认保留。共用或转交设备前，请同时检查协助身份和本机数据，在应用“我的 → 数据与诊断”等对应入口管理缓存与账号；转交设备前可分别清理。

位置、相机与校园网页

雷达签到涉及课程位置，二维码识别可能使用相机或桌面图像；提交的信息用于学校畅课业务。请核对权限和位置，确认提交影响。校园地图使用公开地图瓦片，并在本机按需缓存已浏览内容。

Windows 可通过隔离的内置网页或系统浏览器打开校园网站，目标网站有各自的数据处理规则。各网站按自身规则处理登录状态。

更新与下载

应用从项目 GitHub 正式发布读取公开更新信息和安装包，核对文件大小及 SHA-256；检查和下载安装包不需要校园账号。Windows 发现更新后可后台下载并校验，安装仍需确认。主动选择下载加速线路时，第三方节点会参与公开安装包传输；校验清单来自 GitHub。

Android 使用项目固定签名；Windows 当前没有 Authenticode 发布者签名。来源或安全提示无法确认时，请暂停安装并反馈。

怎样反馈而不泄露信息？

在 GitHub Issues 提供系统和应用版本、操作步骤及脱敏截图。导出诊断日志后先检查内容，不要提交密码、Cookie、Token、身份凭证包或他人的个人数据。维护者资料见 MidiAug GitHub 主页。

此说明随项目功能与数据处理方式同步更新。
